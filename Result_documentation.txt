  - Micro-Batch Size:        2 sequences
  - Grad Accumulation Steps: 32 micro-batches
  - Effective Batch Size:    65,536 tokens / step
  - Precision Selected:      AMP BF16 (Reported by PyTorch 2.11+)

Run 1 Result:
  Step 1/2000 | Train Loss: 11.0044 | Grad Norm: 16.85 | Speed: 731 tok/s | Step Time: 89.70s | VRAM: 13.5 GiB
  Step 2: CUDA out of memory (Tried to allocate 128.00 MiB; 14.28 GiB allocated, 14.55 GiB in use).

Diagnosis & Root Causes:
  1. Software BF16 Emulation: PyTorch 2.11 falsely reported native BF16 on Turing (sm_75). 
     Turing has no BF16 Tensor Cores, falling back to slow software emulation (89.7s/step instead of ~10s).
  2. Activation Memory Spike: With micro-batch=2 across 30 deep layers, storing all activation tensors 
     consumed ~5.0 GB VRAM. Coupled with 9.0 GB static state, memory reached 14.55 GiB and OOMed.

Fixes Implemented & Pushed (Commit: e870236):
  1. Precision: Enforced compute capability check (major >= 8) for native BF16. 
     Tesla T4 (sm_75) now strictly uses hardware FP16 Tensor Cores with GradScaler.
  2. Memory Reduction: Enabled Gradient Checkpointing (recomputes layer activations on backward pass),
     reducing activation VRAM from ~5.0 GB down to ~0.4 GB.
  3. Batch Geometry: Set micro_batch_size = 1, gradient_accumulation_steps = 64 (same 65,536 tokens/step).
  4. Memory Allocation: Added PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True to eliminate fragmentation.
  Expected VRAM with Fixes: ~9.2 GiB (Leaves >5.0 GiB safe headroom on 14.56 GiB T4).

8. EXACT MATHEMATICAL FORMULA & PARAMETER ACCOUNTING (MNC STANDARD)
================================================================================
Master Parameter Equation:
  P = P_embedding + N * (P_attention + P_MLP + P_norm) + P_final_norm + P_output

Architectural Variables for TinyGPT-500M:
  - Vocabulary size (V):                  50,257 (GPT-2 standard tiktoken)
  - Hidden dimension (d):                 1,024
  - Number of layers (N):                 30
  - Query attention heads (H_q):          16 (Head dimension d_k = 1024 / 16 = 64)
  - Key/Value attention heads (H_kv):      4 (GQA 4:1 ratio -> d_kv = 4 * 64 = 256)
  - SwiGLU intermediate dimension (d_ff): 3,456
  - Normalization:                        Pre-norm RMSNorm (zero-mean, scale weight only)
  - Linear projection biases:             None (bias=False across all projections)
  - LM Head Tying:                        Untied (tie_word_embeddings = False)

Detailed Component Calculations:
  1. Token Embedding:
     P_embedding = V * d = 50,257 * 1,024 = 51,463,168

  2. Attention Block per Layer (GQA 4:1 + RoPE):
     - W_q (Query Proj):      d * d     = 1024 * 1024 = 1,048,576
     - W_k (Key Proj):        d * d_kv  = 1024 * 256  =   262,144
     - W_v (Value Proj):      d * d_kv  = 1024 * 256  =   262,144
     - W_o (Output Proj):     d * d     = 1024 * 1024 = 1,048,576
     - RoPE Positional Cache: Pure trigonometric frequencies = 0
     P_attention = d * (d + d/4 + d/4 + d) = 2.5 * d^2 = 2,621,440

  3. MLP / Feed-Forward Block per Layer (3-Matrix SwiGLU):
     - W_gate (Gate Proj):    d * d_ff  = 1024 * 3456 = 3,538,944
     - W_up   (Up Proj):      d * d_ff  = 1024 * 3456 = 3,538,944
     - W_down (Down Proj):    d_ff * d  = 3456 * 1024 = 3,538,944
     P_MLP = 3 * (d * d_ff) = 3 * (1024 * 3456) = 10,616,832

  4. RMSNorm Layers per Layer:
     - input_layernorm:           d = 1024
     - post_attention_layernorm:  d = 1024
     P_norm = 2 * d = 2 * 1024 = 2,048

  5. Total per Transformer Block:
     P_block = P_attention + P_MLP + P_norm
     P_block = 2,621,440 + 10,616,832 + 2,048 = 13,240,320

     Across all N = 30 layers:
     30 * P_block = 30 * 13,240,320 = 397,209,600

  6. Final Normalization Layer:
     P_final_norm = d = 1,024

  7. Output Projection Head (Untied):
     P_output = V * d = 50,257 * 1,024 = 51,463,168

The Master Formula Evaluated:
  P = P_embedding + N * (P_attention + P_MLP + P_norm) + P_final_norm + P_output
  P = 51,463,168 + 30 * (2,621,440 + 10,616,832 + 2,048) + 1,024 + 51,463,168
  P = 51,463,168 + 30 * (13,240,320) + 1,024 + 51,463,168
  P = 51,463,168 + 397,209,600 + 1,024 + 51,463,168
  P = 500,136,960
