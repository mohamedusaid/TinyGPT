5. KEY SCIENTIFIC TAKEAWAYS & PATHWAY TO 500M
================================================================================
1. The Parameter-to-Token Ratio Trap:
   In TinyGPT-6.84M and 15.3M, the parameter-to-token ratio was inverted:
   - 6.84M params on 1,072 tokens = 0.00015 tokens / param
   - 15.3M params on 143k tokens = 0.0093 tokens / param
   Chinchilla scaling laws require >= 20 tokens per parameter to prevent premature memorization.
   At 15.3M, the model achieved minimum validation loss at Step 750 (~23.5 epochs), after which
   it rapidly memorized the training text (+2.33 val loss drift).

2. Embedding Weight Dominance:
   In TinyGPT-15.3M, the token embedding matrix (50,257 x 256) consumes 84.08% of all parameters.
   Only 15.92% remained for actual transformer computation (self-attention and feed-forward networks).
   Scaling to 500M reversed this bottleneck: embeddings account for only 10.3%, leaving 79.4%
   for reasoning depth (30 layers, 1024 dim).

3. Positional Encoding Bottleneck:
   Absolute learned positional embeddings capped sequence length at 256 tokens and could not
   generalize to longer contexts. The 500M model transitioned to Rotary Position Embedding (RoPE),
   enabling dynamic context extension with 0 parameter overhead.

4. Attention Efficiency (MHA vs GQA):
   Standard Multi-Head Attention (MHA) in 15.3M required distinct key/value heads for every query head.
   The 500M model introduced Grouped-Query Attention (GQA, 16 Query heads / 4 Key-Value heads),
   reducing KV cache size by 75% for memory-efficient autoregressive inference.

5. Modern Nonlinearities:
   Replacing LayerNorm with RMSNorm and standard GELU FFN with SwiGLU gating provided smoother gradient
   flow and enhanced representation capacity in the 500M frontier architecture.
